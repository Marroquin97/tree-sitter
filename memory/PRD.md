# ATARAXIA TECH LAB - Product Requirements Document

## Original Problem Statement
Crear una página web para marca personal/empresa ATARAXIA TECH LAB - Un laboratorio creativo-técnico que unifica servicios técnicos (IT/Diseño) con servicios humanos (Capacitación/Mixología).

## Architecture
- **Frontend**: React + Tailwind CSS + Framer Motion + Shadcn UI
- **Backend**: FastAPI + MongoDB
- **Design System**: Industrial Luxury - Negro, gris grafito, dorado mate

## User Personas
1. **Empresas**: Buscan soluciones técnicas (IT, branding, optimización)
2. **Restaurantes/Bares**: Necesitan desarrollo de conceptos gastronómicos y mixología
3. **Profesionales**: Buscan capacitación especializada

## Core Requirements
- Landing page con identidad de marca ATARAXIA TECH LAB
- 3 divisiones: Systems, Experience, Academy
- Portafolio con filtros por categoría
- Formulario de contacto funcional
- Integración WhatsApp
- Diseño responsive
